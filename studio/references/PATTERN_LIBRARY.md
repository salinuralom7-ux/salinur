# PATTERN_LIBRARY.md — what Salinur's references teach (training notebook)

Built up from every reference he sends (training day: 2026-10-06 onwards). Each pattern lists which
references show it, so the most common choices become the default way his videos are edited.
Per-video evidence: `references/<name>/STUDY.md` (+ `study.json`, frames, shots).

## How to use this before every edit
1. Read the **Defaults** section — that is the house style.
2. For each sentence of his script, look up the matching row in **Moment → treatment**.
3. Check **Never** before rendering.

## Never (from references + Salinur's feedback)
- Shrinking the frame / blurry fill at the edges (v3 feedback)
- Noise "whooshes", comedy/quirky music, outlined captions with boxes (v2 feedback)
- Static full-screen cards that freeze the picture (v1 feedback)
- Treating one phrase as separate points ("years of effort" is one point)
